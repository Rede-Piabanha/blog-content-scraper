# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

When GitHub Private Vulnerability Reporting is available for this repository, use the **Security** tab and choose **Report a vulnerability** so the report can be handled privately.

If private vulnerability reporting is not available, contact Rede Piabanha through https://piabanha.net/ and indicate that the message concerns a security vulnerability in Blog Content Scraper.

Do not include credentials, API keys, personal data, private scraped content, or other sensitive information in public reports.

When possible, include the Python version, steps to reproduce, expected behavior, actual behavior, and the potential security impact.
